This is the first release of dichromacy on CTAN. It is a package for simulating
color vision deficiency (CVD) in LaTeX documents. It is currently limited to
LuaTeX.

Except for loading the package, all the user has to do is to set the type of
CVD via `\cvdtype{}` and the severity with `\cvdseverity{}`, for instance:

    \usepackage{dichromacy}

    \cvdtype{deuteranopia}
    \cvdseverity{0.5}

The package will then automatically adjust the colors in the document to
simulate the specified type and severity of CVD. This can be useful for testing
the accessibility of documents for individuals with color vision deficiencies.

Currently the package supports colors defined via the standard LaTeX color
commands (e.g., `\color{red}`) as well as PDF images included via `\includegraphics`.
